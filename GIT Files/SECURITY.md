# Security Policy

## Supported Versions


| Version | Supported          |
| ------- | ------------------ |
| x.1.x   | :white_check_mark: |
| x.x.1   | :red_x_mark:       |


## Reporting a Vulnerability

Please report any security concerns or vulnerabilities directly through the GitHub Issues page for this repository.

If the issue is sensitive, you may mark it as a private security concern when submitting, or describe it in general terms and request follow‑up.
